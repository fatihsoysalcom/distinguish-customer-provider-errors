# Distinguish Customer Provider Errors

This example demonstrates how to distinguish between customer-originated errors and service provider-originated errors in a simulated login process. It highlights that customer errors (e.g., invalid input) are typically identified and handled before provider errors (e.g., system outages) as part of a robust error handling strategy.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
